# Support

ERC-TRUST answers implementation, SDK, specification, and evidence questions
through the channels below. Include the exact commit, profile, command, and
observed result; that is usually enough to reproduce an issue.

## Where to ask

| Need | Use |
| --- | --- |
| Reproducible implementation or SDK defect | Bug issue form |
| Specification, conformance, or evidence question | Specification issue form |
| Documentation defect | Documentation issue form |
| Potential vulnerability | Private path in `SECURITY.md` |
| Standards review | Questions in `docs/COMMUNITY-REVIEW.md` |

Search existing issues before opening a new one.

## Scope

Support covers the reference implementation, the SDK, the specification
drafts, and the published evidence, all of which are unaudited and not for
production. The maintainer does not make legal or compliance determinations,
certify deployments, recommend production or key-management settings, recover
funds or operate tokens, or debug confidential systems through a public
issue, and cannot promise that every question or proposal is accepted or
answered.

Potential vulnerabilities must never be posted through a public support
channel; use the private path in [`SECURITY.md`](SECURITY.md).
