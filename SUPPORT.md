# Support

ERC-TRUST is an unaudited research and reference candidate. It does not offer
production support, integration consulting, deployment review, legal advice,
incident response, or a response-time agreement.

## Where to ask

| Need | Use |
| --- | --- |
| Reproducible implementation or SDK defect | Bug issue form |
| Specification, conformance, or evidence question | Specification issue form |
| Documentation defect | Documentation issue form |
| Potential vulnerability | Private path in `SECURITY.md` |
| Standards review | Questions in `docs/COMMUNITY-REVIEW.md` |

When the repository is private, issue forms are available only to authorized
collaborators. After publication, search existing issues before opening a new
one and include the exact commit, profile, command, and observed result.

## Out of scope

The maintainer cannot:

- determine whether an authority or action is legally valid;
- certify an ERC-3643 deployment as compliant;
- recommend production deployment or key-management settings;
- recover funds, reverse a transaction, or operate a token;
- debug confidential production systems through a public issue;
- guarantee that a question or proposal will be accepted or answered.

Potential vulnerabilities must never be posted through a public support
channel.
